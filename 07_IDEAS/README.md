# 07_IDEAS — inbox идей

Единое место для быстрых идей. Не нужно думать, куда их положить: просто записывайте в `INBOX.md`.

## Как разбирать inbox (раз в неделю)
Для каждой идеи решите, что с ней делать:
- **Контент** → `01_CONTENT/Ideas/Content_Ideas.md`
- **Продукт** → папка нужного продукта в `02_PRODUCTS`
- **Проект** → `Content_From_Project` или `Client_Notes` нужного объекта
- **Бизнес** → `04_BUSINESS/Strategy` или нужный раздел
- **Знание** → `05_KNOWLEDGE`
- **Не нужно** → удалить строку или перенести в `08_ARCHIVE`

Можно попросить Claude: «Разбери inbox идей и разложи по папкам».
