# 05_KNOWLEDGE — экспертная база знаний

Здесь собирается то, что вы знаете как дизайнер и инженер-строитель: правила, нормы, размеры, проверенные решения и типичные ошибки.

Эта база помогает:
- быстро отвечать клиентам;
- делать контент на основе собственной экспертизы, а не общих фраз;
- обучать ассистентов и команду;
- собирать материалы для гайдов и мастер-классов.

## Категории

| Папка | Тема |
|---|---|
| `Kitchens` | Кухни |
| `Bathrooms` | Санузлы |
| `Planning` | Планировки |
| `Lighting` | Освещение |
| `Materials` | Материалы |
| `Windows` | Окна |
| `Curtains` | Шторы и текстиль |
| `Furniture` | Мебель |
| `Construction` | Стройка и инженерия |
| `Common_Mistakes` | Частые ошибки ремонта |

## Как добавлять знания
Одна заметка — одна тема. Название файла: `Высота_столешницы.md`, `Розетки_на_кухне.md`.
Копируйте шаблон `_TEMPLATE_Knowledge.md`.

Каждая заметка — это ещё и готовая основа для Reels или карусели.
