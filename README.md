# valentina-workspace

Рабочее пространство Валентины Спировой, дизайнера интерьера. Здесь собраны контент, продукты, проекты, бизнес, база знаний и бренд.

## С чего начать

- **[DASHBOARD.md](DASHBOARD.md)** — главная страница. Открывайте её первой: что в работе, контент недели, проекты, приоритеты.
- **[07_IDEAS/INBOX.md](07_IDEAS/INBOX.md)** — сюда быстро записывается любая идея.
- **[CLAUDE.md](CLAUDE.md)** — правила для Claude. Их обычно не трогают, но можно дополнять.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `01_CONTENT` | Весь контент для Instagram: сценарии Reels, Stories, карусели, контент-планы, идеи, хуки, журнал опубликованного |
| `02_PRODUCTS` | Услуги и продукты: консультации, гайд, шопинг, мастер-класс по кухням, реклама, дизайн-проекты |
| `03_PROJECTS` | Рабочие проекты по квартирам и домам. Для нового объекта копируется шаблон `_TEMPLATE_Project` |
| `04_BUSINESS` | Стратегия, продажи, партнёры, команда, вакансии, шаблоны документов, процессы, финансы |
| `05_KNOWLEDGE` | Экспертная база знаний: кухни, санузлы, планировки, свет, материалы, окна, шторы, мебель, стройка, ошибки |
| `06_BRAND` | Позиционирование, тон коммуникации, визуальный стиль |
| `07_IDEAS` | Единый inbox для быстрых идей |
| `08_ARCHIVE` | Устаревшие материалы. Здесь их хранят, а не удаляют |

Номера в начале названий нужны только для того, чтобы папки шли по порядку.

## Простые правила

1. **Каждый файл — это обычная заметка.** Формат `.md` — простой текст: `#` — заголовок, `-` — пункт списка, `**слово**` — жирный.
2. **В каждой папке есть `README.md`** — подсказка, что туда класть.
3. **Файлы с `_TEMPLATE_` в начале — шаблоны.** Их не заполняют, а копируют и заполняют копию.
4. **Название файла начинайте с даты:** `2026-10-07_Reels_ошибки_в_кухне.md`. Тогда всё само сортируется по времени.
5. **Ничего не удаляйте** — переносите в `08_ARCHIVE`.
6. **Не знаете, куда положить?** Запишите в `07_IDEAS/INBOX.md`, разберёте потом.

## Как работать с Claude

Можно просто писать задачи обычными словами, например:
- «Придумай 5 хуков для Reels про ошибки в освещении и добавь их в банк хуков»
- «Составь контент-план на следующую неделю»
- «Заведи новый проект: квартира 3-комн., клиент Иванова»
- «Разбери inbox идей и разложи по папкам»

Claude знает правила из `CLAUDE.md` и учитывает уже сохранённые материалы.
