# Published — опубликованное

Журнал всего, что вышло. Он нужен, чтобы:
- не повторяться без необходимости;
- видеть, какие темы и хуки работают лучше;
- возвращаться к сильным темам и делать их продолжение.

Основной файл — `Published_Log.md`. Сами готовые сценарии можно переносить сюда после публикации или оставлять на месте, отметив статус «опубликовано».
