# 01_CONTENT — система контента

## Ритм публикаций

- **3 Reels в неделю**
- **2 карусели в неделю**
- **Воскресенье — без Reels**
- Stories — по ситуации, ежедневно по возможности

## Основные темы

дизайн интерьера · ремонт · планировки · кухни · освещение · материалы · ошибки ремонта · стройка · комплектация · экспертные советы дизайнера

## Путь единицы контента

1. **Идея** → `Ideas/` (или быстро в `07_IDEAS/INBOX.md`)
2. **Хук** → подобрать или придумать в `Hooks/`
3. **План** → поставить в неделю в `Content_Plans/`
4. **Сценарий** → `Reels/`, `Carousels/` или `Stories/` (копия шаблона)
5. **Публикация** → записать в `Published/Published_Log.md`

## Папки

| Папка | Что здесь |
|---|---|
| `Reels` | Сценарии Reels |
| `Stories` | Серии сторис, прогревы, опросы |
| `Carousels` | Тексты слайдов каруселей |
| `Content_Plans` | Планы на неделю и месяц |
| `Ideas` | Банк идей для контента, разложенный по темам |
| `Hooks` | Банк хуков — первых фраз, которые цепляют |
| `Published` | Журнал всего опубликованного и результатов |

## Проверка перед публикацией

- [ ] Есть сильный хук в первые 1–2 секунды / на первом слайде
- [ ] Есть конкретная польза: человек узнаёт, как сделать или как не ошибиться
- [ ] Видна экспертиза: опыт, стройка, реальный объект
- [ ] Нет штампов («интерьер вашей мечты», «уют и гармония»)
- [ ] Тон спокойный и уверенный, без рекламного давления
- [ ] Визуал по стилю бренда (`06_BRAND/Visual_Style.md`)
