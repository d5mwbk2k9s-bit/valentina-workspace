# 03_PROJECTS — рабочие проекты

Здесь хранятся объекты: квартиры и частные дома.

## Как завести новый проект

1. Скопируйте папку `_TEMPLATE_Project` целиком.
2. Назовите копию: `2026-10_Квартира_Фамилия` или `2026-10_Дом_Фамилия`.
3. Заполните карточку проекта — `README.md` внутри папки.
4. Добавьте объект в таблицу «Текущие проекты» в `DASHBOARD.md`.

Проще всего попросить Claude: «Заведи новый проект: дом 150 м², клиент Петрова».

## Что внутри каждого проекта

| Папка | Что хранить |
|---|---|
| `Brief` | Анкета клиента, пожелания, бюджет, сроки |
| `Planning` | Обмеры, варианты планировок, решения |
| `Concept` | Стиль, референсы, мудборды, визуализации |
| `Materials` | Отделочные материалы, поставщики, цены |
| `Furniture` | Мебель и комплектация, заказы, сроки поставки |
| `Lighting` | Сценарии и план освещения, светильники |
| `Construction` | Стройка: этапы, бригады, авторский надзор, замечания |
| `Client_Notes` | Встречи, договорённости, правки клиента |
| `Content_From_Project` | Что с объекта можно превратить в контент |

## Завершённые проекты
После сдачи объекта перенесите папку в `08_ARCHIVE/Projects/`. Лучшие решения и ошибки — в `05_KNOWLEDGE`, фото — в портфолио.
