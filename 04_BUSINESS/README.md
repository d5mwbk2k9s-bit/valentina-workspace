# 04_BUSINESS — бизнес

| Папка | Что хранить |
|---|---|
| `Strategy` | Цели на год и квартал, направления развития, решения о продуктах |
| `Sales` | Заявки, воронка, скрипты ответов, отказы и их причины |
| `Partners` | Поставщики, салоны, подрядчики, условия сотрудничества |
| `Team` | Кто в команде, роли, контакты, договорённости |
| `Vacancies` | Описания вакансий, требования, кандидаты |
| `Templates` | Шаблоны документов: договор, КП, анкета, акт |
| `Processes` | Как устроена работа: пошаговые инструкции |
| `Finance` | Доходы, расходы, цены, планы по выручке |
