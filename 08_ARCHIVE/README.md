# 08_ARCHIVE — архив

Сюда переносится всё устаревшее. Это лучше, чем удалять: архив всегда можно открыть.

## Как архивировать
- Сохраняйте исходную структуру: например, `08_ARCHIVE/01_CONTENT/Reels/...`.
- Завершённые объекты переносите в `08_ARCHIVE/Projects/`.
- Старые прайсы и версии бренда — с датой в названии: `2026-10_прайс.md`.
